# Как помочь проекту

Спасибо за интерес к каталогу VPN-ботов для России! Здесь — всё, что нужно знать перед первым Pull Request.

## Как устроен репозиторий

- [`data/bots.json`](data/bots.json) — единственный источник данных: список ботов и их порядок в таблице.
- [`README.md`](README.md) — таблица ботов между маркерами `<!-- BOTS:START -->` и `<!-- BOTS:END -->` **генерируется** из `data/bots.json`.
- `scripts/generate-readme.mjs` — генератор: пересобирает таблицу и при изменении данных обновляет бейдж `updated-YYYY.MM`.
- `scripts/validate.mjs` — валидатор: формат записей, дубликаты (хендлы Telegram нечувствительны к регистру).
- `.github/workflows/validate.yml` — CI: на каждый push и PR проверяет данные и актуальность README.

> **Важно:** не редактируйте таблицу в README вручную — при следующем запуске генератора правки будут перезаписаны.

## Добавить бота

1. Убедитесь, что бота ещё нет в списке (`Ctrl+F` по `data/bots.json`).
2. Добавьте запись в конец массива — или в начало, если бот должен занять первое место:

   ```json
   { "handle": "example_vpn_bot" }
   ```

3. Перегенерируйте README и проверьте данные (нужен Node.js 18+, зависимостей нет):

   ```bash
   node scripts/generate-readme.mjs
   node scripts/validate.mjs
   ```

4. Откройте PR по шаблону: укажите протокол, способ оплаты и дату проверки бота.

## Сообщить о нерабочем боте

- Быстрее всего — Issue по шаблону «Нерабочий бот» (метка `broken`).
- Ещё быстрее — сразу Pull Request: удалите запись из `data/bots.json` и выполните `node scripts/generate-readme.mjs`. Таблица и нумерация пересоберутся автоматически, массовых правок в диффе не будет.

## Правила

- **VPN и прокси, которые реально выдают доступ**: VLESS/Reality, WireGuard, Shadowsocks, Outline, MTProto/socks5. Прочие сервисы — только по согласованию в PR (каталог тематический).
- **Ссылки — только вида `https://t.me/<handle>`**, без реферальных, UTM- и `?start=`-параметров. Генератор их не добавляет, а CI отклонит ручные правки таблицы.
- **Без дубликатов.** Telegram-хендлы нечувствительны к регистру: `@FooBot` и `@foobot` — один и тот же бот.
- Хендл: 5–32 символа, `A-Z`, `a-z`, `0–9`, `_`.

## Локальная проверка

```bash
node scripts/generate-readme.mjs          # пересобрать таблицу в README.md
node scripts/generate-readme.mjs --check  # проверить, что README актуален (без записи)
node scripts/validate.mjs                 # проверить data/bots.json
```

Те же команды выполняет CI: если README не пересобран после правки `data/bots.json`, PR не пройдёт проверку.

## Стиль

- Язык README — русский, тон — лаконичный, без маркетингового шума.
- Порядок ботов в таблице задаётся порядком объектов в `data/bots.json`.
- Заголовки и навигацию менять можно, но проверяйте, что ссылки-якоря не сломались.
