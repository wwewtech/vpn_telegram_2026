# Code of Conduct / Кодекс поведения

## English

We want this project to be welcoming to everyone. Please be respectful in issues,
pull requests and discussions.

### Expected behavior

- Be kind, constructive and on-topic.
- Assume good faith; ask questions before judging.
- Report dead bots or problems with the catalog constructively — it helps everyone.

### Unacceptable behavior

- Harassment, personal attacks, hate speech.
- Spam, self-promotion of unrelated services, referral link injection.
- Publishing others' private information without consent.

### Enforcement

Report violations privately to the repository maintainer (@wwewtech).
Contributions violating this code may be removed, and repeat offenders blocked.

---

## Русский

Мы хотим, чтобы проект был дружелюбным для всех. Пожалуйста, будьте взаимно вежливы
в Issue, Pull Request и обсуждениях.

### Ожидаемое поведение

- Доброжелательность, конструктив и тема каталога.
- Считайте, что собеседник действует добросовестно; уточняйте, прежде чем критиковать.
- Сообщайте о нерабочих ботах и проблемах каталога конструктивно — это помогает всем.

### Недопустимое поведение

- Травля, личные нападки, язык вражды.
- Спам, самореклама нерелевантных сервисов, вставка реферальных ссылок.
- Публикация чужих личных данных без согласия.

### Как сообщить о нарушении

Напишите приватно мейнтейнеру репозитория (@wwewtech).
Нарушающие правила материалы могут быть удалены, а нарушители — заблокированы.
